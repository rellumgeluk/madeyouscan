# Raising awareness💡

#### About the project

![Message page](images/about.png)

 A QR code that can be found around places to conscientize people to be mindful before scanning a unknown qr code on the street.

When the qr code is scanned, the person will be redirected to a page and in this page they will receive a message informed that they have been hacked. However, the next message will inform that this is nothing more than a joke and will warn the person to don't go around scanning random qr codes.
Additionally, on the right bottom part this page, they will be able to check for further information about it. Which leads to the message page.
